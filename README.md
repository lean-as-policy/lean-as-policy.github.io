# LEAP project page

Static project page for *LEAP: Lean as Policy for Verifiable Robot Control*.

- `index.html` – the page (no build step)
- `static/style.css`, `static/page.js` – styles and the small scripts for videos, the pipeline demo and the library view
- `static/figures/` – figures exported from the paper PDFs
- `static/videos/` – overview video, real-robot rollouts (4× speed) and the two pipeline-demo episodes; H.264, no audio except the overview
- `static/posters/` – first-frame posters for the videos

Preview locally with `python3 -m http.server` and open http://localhost:8000.
Serve with GitHub Pages from the repository root.
